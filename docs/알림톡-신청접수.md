# 신청 접수 알림톡 — 등록용 문구 · 켜는 순서

고객이 인투마케팅 신청서(홈페이지 · 디자인 · 영상 · SNS · 블로그·리뷰)를 내면,
신청서에 적은 휴대폰 번호로 **「신청 접수 완료」 알림톡**이 자동으로 갑니다.
카카오톡이 없거나 받지 못하면 솔라피가 **문자로 대신** 보냅니다.

> 🔴 **이 저장소는 공개입니다.** API 키 · 비밀값 · 템플릿 코드를 이 문서에 적지 마세요.
> 🔴 **변수 이름은 코드(`supabase/functions/apply-notify/index.ts`)와 한 글자도 다르면 안 됩니다.**
> 문구를 고치려면 코드도 같이 고쳐야 합니다.

---

## 1. 어떻게 움직이나

```
신청서 제출 (apply/form.js · apply/index.html → requests 표)
  → DB 트리거 on_mkt_request_created   (center='mkt' 이고, 손님 본인 계정으로 낸 건만)
  → Edge Function apply-notify          (신청 건을 DB 에서 다시 읽고 조건 확인)
  → 솔라피 API → 카카오 → 고객 카카오톡   (실패하면 문자로 대신)
  → mkt_alimtalk_log 에 결과 기록
```

**보내지 않는 경우** (기록에는 `skipped` 와 이유가 남습니다)

| 이유 코드 | 뜻 |
|---|---|
| `NO_USER` | 관리자가 어드민에서 직접 넣은 건 |
| `MATERIAL_FOLLOWUP` | 계약 뒤 「제작 자료」 제출 — 신청이 아니므로 |
| `KIND_NOT_COVERED` | 홈페이지 · 앱 · 프로그램 · SNS · 디자인 · 영상 · 블로그·리뷰 외의 종류 |
| `NOT_MOBILE` | 휴대폰 번호(010 등)가 아님 |
| `DAILY_LIMIT` | 같은 번호 24시간 5통, 같은 계정 24시간 10통 초과 (남의 번호를 적는 장난 방지) |
| `PROVIDER_NOT_CONFIGURED` | 솔라피 키 · 템플릿 코드가 아직 안 들어감 — **심사 전에는 이 상태로 기록만 남습니다** |

학원지원센터(`center='esc'`) 신청은 이 알림톡을 받지 않습니다.

## 2. 솔라피에 등록할 템플릿

| 항목 | 값 |
|---|---|
| 발신프로필 | **인투마케팅** 채널 (2026-10-08 승인) |
| 템플릿명 | `인투마케팅_신청접수` |
| 형태 | 강조표기형 |
| 강조표기 보조문구 | `인투마케팅` |
| 강조표기 제목 | `신청이 접수되었습니다` |
| 카테고리 | 서비스이용 > 이용안내/공지 (콘솔에서 가장 가까운 항목) |
| 환경변수 | `ALIMTALK_TPL_APPLY` ← 승인 후 받은 템플릿 ID |

**본문**

```
#{고객명}님, #{신청분야} 신청이 접수되었습니다.

- 접수번호: #{접수번호}
- 접수일시: #{접수일시}

담당자가 신청 내용을 확인한 뒤 연락드립니다.
영업시간(월~금 09:00~20:00, 공휴일·회사 휴무일 제외) 외에 접수된 건은 다음 영업일 09:00 접수로 처리됩니다.

신청 내역은 아래 「신청 내역 확인」에서 보실 수 있습니다.
문의: 010-7318-1790
```

**버튼**

| 버튼 | 유형 | 버튼명 | 모바일 / PC 링크 |
|---|---|---|---|
| 1 | 웹링크 | `신청 내역 확인` | `https://intomarketing.co.kr/my/` (둘 다 같은 주소) |

**변수 예시** (심사 때 함께 적습니다)

| 변수 | 예시 | 코드에서 채우는 값 |
|---|---|---|
| `#{고객명}` | 홍길동 | 담당자 이름 → 없으면 상호 |
| `#{신청분야}` | 홈페이지 제작 | 홈페이지 제작 · 앱 제작 · 프로그램 제작 · SNS 채널 · 그래픽 디자인 · 영상 제작 · 블로그 · 리뷰 |
| `#{접수번호}` | 3F9A12BC | 홈페이지 신청서는 화면의 「신청 번호」, 나머지는 신청 건 번호 앞 8자리 |
| `#{접수일시}` | 2026년 10월 21일 오후 3:05 | 저장된 시각 (한국 시간) |

**심사 통과 원칙**
- 손님이 직접 신청한 데 따른 **정보성** 안내입니다. 「할인」 「무료」 「이벤트」 「지금 신청」 같은 말을 넣지 않습니다.
- 버튼 이름 · 제목에는 변수를 쓰지 않습니다.
- 영업시간 문장은 기술팀 검토 자료(2026-10-10)의 「전 팀 공통 고객 안내 기준」을 옮긴 것입니다. 기준이 바뀌면 재심사입니다.

## 3. 켜는 순서

| 순서 | 할 일 | 어디서 | 누가 |
|---|---|---|---|
| 1 | 위 템플릿 심사 신청 | 솔라피 콘솔 → 알림톡 템플릿 (발신프로필 **인투마케팅**) | 행정 |
| 2 | `supabase/migrations/20261021120000_mkt_apply_alimtalk.sql` 적용 | Supabase(qkvebwxewttqtcryfycy) → SQL Editor | 기술 |
| 3 | 비밀값 꺼내서 함수 비밀값에 넣기 (파일 맨 위 SQL 참고) | Edge Functions → Secrets → `APPLY_HOOK_SECRET` | 기술 |
| 4 | 함수 배포 — `supabase functions deploy apply-notify --no-verify-jwt` | 터미널 | 기술 |
| 5 | 솔라피 값 넣기 (아래 표) | Edge Functions → Secrets | 기술 |
| 6 | 본인 계정으로 신청서 1건 → 카톡 도착 · `mkt_alimtalk_log` 의 `sent` 확인 | — | 기술 |

1~4 는 심사를 기다리는 동안 먼저 해 두어도 됩니다. 5 를 넣기 전까지는 고객에게 아무것도 가지 않습니다.

**Edge Function 비밀값**

| 이름 | 넣을 값 |
|---|---|
| `APPLY_HOOK_SECRET` | 3번에서 꺼낸 값 |
| `SOLAPI_API_KEY` | 솔라피 API Key |
| `SOLAPI_API_SECRET` | 솔라피 API Secret |
| `SOLAPI_PFID` | **인투마케팅** 채널의 발신프로필 키(pfId) — ESC 학원지원 채널 키가 아닙니다 |
| `SOLAPI_SENDER` | 솔라피에 등록된 발신번호 (문자 대체발송용) |
| `ALIMTALK_TPL_APPLY` | 1번 템플릿 승인 후 받은 템플릿 ID |

## 4. 확인하는 법

```sql
-- 최근 발송 20건
select created_at, request_id, status, error, variables->>'#{신청분야}' as 분야
  from public.mkt_alimtalk_log order by created_at desc limit 20;
```

`failed` 가 보이면 `error` 칸에 솔라피가 돌려준 이유가 들어 있습니다.
가장 흔한 원인은 ① 템플릿 문구 · 변수 이름 불일치 ② pfId 가 다른 채널 것 ③ 발신번호 미등록입니다.
