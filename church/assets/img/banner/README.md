# 홈 배너 사진

여기에 파일을 넣으면 홈 화면 배너의 배경이 됩니다.
파일이 없으면 지금처럼 색과 아이콘으로 나옵니다 — 빌드는 깨지지 않습니다.

| 파일 이름 | 어느 배너 |
|---|---|
| `homepage.jpg` | 홈페이지 제작 |
| `market.jpg` | 중고 장터 (쓰던 음향과 악기를) |
| `jobs.jpg` | 교역자 구인 |
| `guesthouse.jpg` | 게스트하우스 |

확장자는 `.jpg` · `.jpeg` · `.png` · `.webp` 를 모두 알아봅니다.
가로로 긴 사진(2:1 안팎)이 잘 맞고, 글자가 아래쪽에 얹히므로
사진의 아랫부분은 비어 있는 편이 좋습니다.

파일을 넣은 뒤 `npm run build` 를 한 번 돌리면 반영됩니다.
