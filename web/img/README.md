# /web/img/ — 홈페이지 제작 세부페이지 이미지

아래 이름으로 파일을 **덮어쓰면** `/web/` 화면이 바로 바뀝니다. 코드를 고칠 필요가 없습니다.

지금 들어 있는 같은 이름의 파일은 **1×1 빈 자리표시 파일**입니다. 화면은 이 파일을 보고
「아직 그림이 없다」고 판단해 어두운 자리(또는 옅은 점선 자리)만 보여 줍니다(`data-tbd`).
가로 · 세로가 3px 이상인 실제 그림이 들어오면 자리표시를 걷고 그림을 보여 줍니다.

| 파일 이름 | 자리 | 형식 · 권장 크기 | alt |
|---|---|---|---|
| `hero-photo.jpg` | 히어로 오른쪽 둥근 사진 | JPG, 가로 사진, 긴 변 2000px 이상 | 사진 내용대로 — `index.html` 의 `data-alt` 를 고치십시오 |
| `deco-hero-top.png` | 히어로 오른쪽 위 3D 장식 | 투명 배경 PNG, 긴 변 1200px 이상 | 장식 (`alt=""`) |
| `deco-hero-bottom.png` | 히어로 왼쪽 아래 3D 장식 | 투명 배경 PNG, 긴 변 1200px 이상 | 장식 (`alt=""`) |
| `deco-problem.png` | 2번 섹션 상자 오른쪽 아래 그래픽 | 투명 배경 PNG, 긴 변 900px 이상 | 장식 (`alt=""`) |
| `apply-quote.png` | 신청서 「예상 금액」 화면 캡처 | PNG | 신청서의 예상 금액 화면 |
| `apply-preview.png` | 제작 자료 「홈페이지 미리 보기」 화면 캡처 | PNG | 제작 자료의 홈페이지 미리 보기 화면 |

🔴 `design-main.png` · 레퍼런스 속 노트북 사진 · 3D 리본 · 3D 지폐·동전은 교육용 Canva 템플릿 요소라
상업용 사이트에 쓸 수 없습니다. 잘라 쓰거나 비슷하게 따라 그린 것을 넣지 마십시오.

- 받은 파일은 웹용으로 줄여 넣으십시오(사진은 긴 변 2000px 안팎, 수백 KB 이하). 원본은 따로 보관합니다.
- WebP 로 바꿔 쓰려면 파일 이름의 확장자가 달라지므로 `index.html` 의 `src` 도 같이 바꾸십시오.
- GitHub Pages 는 그림을 몇 분 동안 캐시합니다. 바꾼 뒤 바로 안 보이면 새로 고침(Ctrl+F5) 하십시오.
